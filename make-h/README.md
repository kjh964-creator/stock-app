# make-h — 앞으로의 작업 폴더

앞으로 새로 만드는 작업물은 모두 이 폴더 안에 넣습니다.

## 규칙

- **새 작업물은 여기에.** 새 기능·새 스크립트·새 문서는 `make-h/` 아래에 만듭니다.
- **기존 파일은 그대로.** 저장소 루트의 `app.py`, `analyze_all.py`, `analyze_stock.py`,
  `server.py`, `data/`, `*.bat` 등은 위치를 옮기지 않습니다.
  (경로가 `.bat` 파일과 배포 설정에 박혀 있어서 옮기면 전부 같이 고쳐야 합니다.)
- **작업 단위로 하위 폴더.** 주제가 다르면 `make-h/<주제이름>/` 으로 나눕니다.

## 구조

```
stock-app/
├── app.py              ← 기존 (Streamlit 웹앱)
├── analyze_all.py      ← 기존
├── data/               ← 기존 (리포트·보관함)
└── make-h/             ← 앞으로 여기
    └── README.md
```

## 폰에서 작업하는 법

PC 없이 폰만으로 진행합니다.

1. 폰에서 claude.ai/code 열기
2. 한국어로 무엇을 만들지 말하기
3. 클라우드에서 코드가 작성되고 GitHub에 저장됨

파일은 폰 저장공간이 아니라 GitHub에 남습니다. 폰을 바꿔도 그대로입니다.

자세한 접속·사용법은 저장소 루트의 `폰_접속_가이드.md` 참고.
